# COLX Student Results System

My second Python project!

## About
A simple student results management system built with Python.

## Features
- Collects names of 3 students
- Accepts 4 scores per student
- Calculates individual total scores
- Calculates individual averages
- Gives performance remarks
- Calculates the class average
- Identifies the highest average and top student

## Technology
- Python

## Concepts Used
- Variables
- User input
- Arithmetic operations
- If, elif and else
- Comparison operators
- The `max()` function
